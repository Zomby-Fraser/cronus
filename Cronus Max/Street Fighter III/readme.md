# Street Fighter III Trials Automation Script

## Overview
This script automates the process of completing character trials in Street Fighter III for Player 1. It is designed to handle menu navigation, trial selection, and combo execution, ensuring progress is recorded correctly. This script is ideal for grinding through trial challenges but can also assist with unlocking related achievements.

A majority of these scripts have been recorded by **sTuNtAsTiC b0sS** and put into code by **XxFrAsZeRxX**.

Only 1 trial needs to be done manually and that is the first Handicap Trials. Using all of these scripts will give you 54/55 trials needed for the trophy.

## Setup Instructions
- The correct starting position for each trial is described in the script comments. Make sure Player 1 is positioned exactly as noted before beginning, or the inputs may not line up correctly.

### Starting the Script
All scripts **start with LS (left stick)** and **end with RS (right stick)**.

## Script Behavior
- Because a majority of these scripts were recorded from **actual gameplay**, some may appear to make mistakes or misfire inputs during execution. Despite this, they all do work. Let the entire script play out from start to finish and be aware that it may need to be run several times before it completes successfully. If a retry is needed, just pause and hit reset and reposition.
